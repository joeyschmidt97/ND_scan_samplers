# ND_scan_samplers

Sampler algorithms for adaptive N-D parameter scans (VWRS, VURS, GP
uncertainty/gradient, space-filling, sg_lib and SG++ sparse grids), with the
benchmarks that compare them. Each sampler places expensive simulations (GENE
runs, in the target use) one batch at a time; the benchmarks score them on
synthetic 2-D to 8-D surfaces and on replayed MGKDB scan pools.

Continues `joeyschmidt97/UQ_discontinuties` (a fork of
[ionutfarcas/UQ_discontinuties](https://github.com/ionutfarcas/UQ_discontinuties))
with full history; the root commit is Ionut Farcas's.

## Layout

```
src/                  the library
  strategies.py       placement policies (VWRS, VURS, GP, space-filling) and run_arm
  resolution/         local-variation and fill estimates the policies use
  arms/               sg_lib, SG++ and GP adapters
  nersc/              setup script, slurm jobs, run-progress monitor, runbook
tests/                pytest modules (test_*.py) and manifold.py, a cheap test oracle
  benchmarks/         harnesses that exercise src/
    benchmark2d/      2-D surfaces, policies, merge, report
    benchmark3d/      3-D Ionut proxy slices
    benchmarknd/      5-D/8-D cases, MGKDB pool replay, collect, checks, tables
scripts/
  data/               dataset loader and generators, Ionut proxies, MGKDB pool export
  experiments/        one-off and registered experiment runners
  analysis/           registered analyses and report renderers
data/                 frozen datasets and pools (see data/README.md)
results/<study>/      outputs, each with the commands that produced it
docs/                 RESULTS, EXPERIMENTS, BENCHMARK_2D, BENCHMARK_ND
outputs/              raw per-run working directories, not tracked
```

Anything under `results/` is regenerated by the commands recorded beside it;
nothing there is edited by hand.

## Setup

Imports are absolute from the repo name (`from ND_scan_samplers.src.strategies
import run_arm`), so the directory containing `ND_scan_samplers/` must be on
`PYTHONPATH`. Commands below run from the repo root.

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements-sgpp.txt   # full field, incl. SG++ 3.3.1 (Linux, NumPy 1.x)
export SG_LIB_PATH=/path/to/sensitivity-driven-sparse-grid-approx
export PYTHONPATH="$(dirname "$PWD")"
```

On Windows, `requirements.txt` covers the built-in arms (no SG++). On NERSC,
follow [src/nersc/NERSC_RUNBOOK.md](src/nersc/NERSC_RUNBOOK.md).

## Run

```bash
python -m ND_scan_samplers.tests.benchmarks.benchmark2d --quick --output outputs/quick
python -m ND_scan_samplers.tests.benchmarks.benchmarknd --cases 5d-m2-rotated --seeds 0 --output outputs/nd-run/5d-m2-rotated-s0
python -m ND_scan_samplers.tests.benchmarks.benchmarknd.pool --help      # MGKDB pool replay
```

Full commands and protocols: [2-D benchmark](docs/BENCHMARK_2D.md),
[5-D/8-D benchmark](docs/BENCHMARK_ND.md), [GP experiments](docs/EXPERIMENTS.md),
[datasets](data/README.md). Findings: [docs/RESULTS.md](docs/RESULTS.md).

## Tests

```bash
python -m pytest tests -q                    # everything; SG++/sg_lib tests skip if absent
python -m pytest tests/test_sgpp_arm_mock.py -q   # run the SG++ mock on its own: it replaces the backend at import
```
